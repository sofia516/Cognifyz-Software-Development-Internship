# Level 1, Task 1: Number Guessing Game

A simple text-based Python game for the Cognifyz Technologies Software Development Internship.

## How to play

Run the game with:

```bash
python main.py
```

The game chooses a number from 1 to 100. You have seven valid guesses. It gives a higher or lower hint after each incorrect guess. Non-numeric and out-of-range input is handled with a friendly message and does not use an attempt. After each round, you can choose whether to play again.

## Run the tests

```bash
python -m unittest -v
```
