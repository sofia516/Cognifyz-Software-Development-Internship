# Level 1, Task 2: Number Pattern Generator

A text-based Python program that generates four number patterns using loops:

1. Increasing triangle
2. Decreasing triangle
3. Number pyramid
4. Floyd's triangle

Run the program with:

```bash
python main.py
```

Choose a pattern from the menu and enter a positive whole number of rows. Invalid choices and row counts receive a clear message.

Run the unit tests with:

```bash
python -m unittest -v
```
