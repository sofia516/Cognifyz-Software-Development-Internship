# Level 2, Task 4: Temperature Converter

A menu-driven Python program that converts temperatures from Celsius to Fahrenheit and Fahrenheit to Celsius. It accepts decimal and negative values, validates numeric input, and displays converted values to two decimal places. The menu remains available for repeated conversions until you choose Exit.

Run the program with:

```bash
python main.py
```

Run the unit tests with:

```bash
python -m unittest -v
```
